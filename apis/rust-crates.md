# Rust crate 说明

Rolldown 也以 Rust crate 的形式发布在 crates.io 上。

主要的 crate 是 [rolldown](https://crates.io/crates/rolldown)。

## 维护政策

使用这些 crate 前，请务必了解以下政策：

- 这些 crate 不遵循语义化版本规范，任何版本都可能引入破坏性变更。
- 项目不会提供这些 crate 的文档。
- 团队不会处理仅影响 Rust crate 的问题，此类 issue 将被关闭。不过，我们愿意接受针对这些用例的 pull request。

我们的重点是 JS 包，并希望尽可能降低这些 crate 的维护成本。如果有长期贡献者愿意承担这一领域的维护工作，我们可以重新审视后两项政策。
